## Description

A personal playground for exploring and experimenting with Artificial Intelligence.

This repository contains practical examples, experiments and small projects
created while learning and working with modern AI technologies.

The focus is on understanding how things work under the hood — not just
using ready-made solutions.

Topics include:

- Generative AI & LLMs
- Retrieval Augmented Generation (RAG)
- Embeddings & Vector Databases
- AI Agents
- Model Context Protocol (MCP)
- AI-assisted Development
- Automation & DevOps

> Learn. Build. Experiment. Understand.
